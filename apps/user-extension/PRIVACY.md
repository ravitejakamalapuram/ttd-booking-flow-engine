# Privacy Policy for Booking Flow Runner

Last Updated: September 2026

Booking Flow Runner ("the Extension") is committed to protecting user privacy and ensuring full transparency regarding data handling.

## 1. Data Collection & Storage
- **Local Storage Only:** The Extension stores user preferences, workflow configurations, and performance timing metrics strictly within Chrome's local extension storage (`chrome.storage.local`).
- **No Personal Data Collected:** The Extension does not collect, track, or record any personally identifiable information (PII), credentials, passwords, financial details, or payment information.
- **No Remote Servers or Analytics:** The Extension does not send telemetry, analytics, or behavioral data to any third-party or remote servers.

## 2. Permissions & Use
- **storage:** Used exclusively to store workflow run settings, step verification preferences, and local latency metrics on device.
- **tabs:** Used solely to interact with and coordinate workflow step execution on the active booking portal tab.
- **host_permissions (`https://ttdevasthanams.ap.gov.in/*`):** Used strictly to inspect DOM element readiness and automate authorized navigation steps on the booking portal.
- **host_permissions (`https://raw.githubusercontent.com/*`):** Used to retrieve verified, open-source workflow configuration definitions.

## 3. Third-Party Sharing
The Extension does not sell, transfer, or disclose any user data to third parties.

## 4. Contact
For any privacy questions, please open an issue on the repository.
