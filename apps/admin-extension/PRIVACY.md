# Privacy Policy for Booking Flow Admin Recorder

Last Updated: September 2026

Booking Flow Admin Recorder ("the Extension") is an authoring tool designed for recording and authoring versioned booking workflows directly from the live DOM.

## 1. Data Collection & Storage
- **Local Storage Only:** Workflow sequences, step definitions, and recorder settings are stored locally in Chrome's extension storage (`chrome.storage.local`).
- **No Personal Data Collected:** The Extension does not collect, track, or record any personally identifiable information (PII), passwords, financial details, or payment information.
- **No Remote Servers or Analytics:** The Extension operates entirely offline and locally within the browser; no data is transmitted to remote servers.

## 2. Permissions & Use
- **activeTab & tabs:** Used solely to inspect DOM elements on the active tab when authoring workflow steps.
- **storage:** Used to persist locally recorded workflow definitions on device.
- **host_permissions (`https://ttdevasthanams.ap.gov.in/*`):** Used strictly to identify DOM element selectors and author workflow steps on the target portal.

## 3. Third-Party Sharing
The Extension does not sell, transfer, or disclose any user data to third parties.

## 4. Contact
For any privacy questions, please open an issue on the repository.
