# Privacy Policy

This repository ships two Chrome extensions. Each has its own privacy policy:

| Extension | Policy (source) | Published URL |
| :--- | :--- | :--- |
| Booking Flow Runner | [apps/user-extension/PRIVACY.md](apps/user-extension/PRIVACY.md) | https://ravitejakamalapuram.github.io/booking-flow-runner.html |
| Booking Flow Admin Recorder | [apps/admin-extension/PRIVACY.md](apps/admin-extension/PRIVACY.md) | https://ravitejakamalapuram.github.io/booking-flow-recorder.html |

In short: both extensions store their data only in Chrome's local extension
storage, collect no personal information, send no analytics or telemetry to
any server, and never sell or share user data. The runner fetches published
flow definitions (declarative JSON) from `raw.githubusercontent.com`; no user
data is sent with those requests.
